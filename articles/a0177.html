01 GLM-4.5介绍

这次发布，是智谱旗下模型今年最重要的一次重磅升级，从GLM-4进化到GLM-4.5。

目前发布了两款最新的旗舰模型：GLM-4.5和GLM-4.5-Air。

GLM-4.5是最强版本，Air是轻量快速版本。

智谱这次重点关注并且加强了模型的三大能力： 智能体能力、推理能力、编程能力 。

在12个数据评测集上，打一个综合平均分，GLM-4.5取得了全球模型第三、国产模型第一、开源模型第一的成绩。

对各种数据集上靠前的排名，大家可能已经见怪不怪了，大家可以去实际体验一下！

今天我用的时候，算力资源非常紧张，很多时候因为用户太多任务直接终止了，和早期用Manus的状态差不多。

智谱这次还发布了详细的技术报告，从智谱的报告里面可以看到一个很关键的点，不知道大家注意到没。

我看完后，脑子里浮现一句话：模型正在智能体化。

各方面解决的都是智能体落地的关键问题。

智能体工具能力方面 ，GLM-4.5在工具调用上发力，平均成功率达到了90.6%，超越了Claude-4-Sonnet（89.5%）、Kimi-K2（86.2%）和Qwen3-Coder（77.1%），在代理式编程任务中展现出更高的可靠性和效率。

推理能力方面 ，在国内是比较领先的，和国际上的模型现在差距也不大。

编程能力方面 ，帕累托前沿分析显示GLM-4.5这次在性能和模型参数上取得了一个不错的成绩。

分析图（模型位置越偏左上角越好）

并且GLM-4.5通过多种强化学习的手段在不断加强模型这三大方面的能力。

强化学习

今年，正是智能体落地应用的关键之年，模型的智能体能力越来越重要了，而且看到模型正在智能体化！

GLM-4.5提供了多种使用方式。在智谱清言 https://chatglm.cn 中可以使用，但是我比较推荐智谱z.ai网站，这里可以体验到最新最强的模型。

体验地址：https://chat.z.ai/

记得选择GLM-4.5模型，或者GLM-4.5-Air，我体验下来还是GLM-4.5模型效果更好。

03 GLM-4.5 + Claude Code

这次还有一个很重磅的是将GLM-4.5和Claude Code结合使用！

官方提供了给Claude Code使用的API接口，并且设计了相应的文档。

GLM-4.5接入Claude Code

不得不说，真是全面，Claude Code、Gemini CLI、Cline等六大主流的AI编程助手都提供了接入方案。

使用下面的指令就可以直接使用GLM-4.5，记得填入你的API\_KEY，从智谱开放平台获取：https://bigmodel.cn/usercenter/proj-mgmt/apikeys

export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic

export ANTHROPIC_AUTH_TOKEN={YOUR_API_KEY}

保持技术敏感度，拥抱新工具，但更要培养那些AI暂时无法替代的能力——创造力、同理心，以及最关键的，学会提出好问题的能力。
