前两天找到一个叫 awesome-design-md 的仓库，把 Stripe、Figma、Notion 等 55 家大厂的设计规范全部提取成了 Markdown 文档

沿着这条线一路搜，发现各个领域专家都在做把自己的专业写成 Markdown，喂给 Agent。

下面整理我找到的所有github 项目，附地址

1、agents.md 是目前最通用的 Agent 指令格式，放在项目根目录所有主流 Agent 都可以用， 地址：agents.md

2、llms.txt 让网站对 Agent 可读，用 Markdown 描述网站内容结构。目前已有 1000+ 网站实现了这个标准。

地址：llmstxthub.com

3、awesome-design-md，55+ 大厂设计规范，4.3k stars。上面提到的

地址：github.com/VoltAgent/awesome-design-md

4、taste-skill，解决 Agent 生成前端千篇一律的问题。提供三个旋钮：设计冒险度、动画强度、视觉密度，可以从1 到 10 调节程度。

地址：github.com/Leonxlnx/taste-skill

5、Superpowers，121k stars，目前这个领域 star 最多的项目。一套完整的软件开发方法论，用 Markdown 编码成 Agent 必须执行的工作流。Agent

地址：https://github.com/obra/superpowers

6、GStack，YC CEO Garry 开源的Agent配置。28 个命令，每个激活一种"角色"：CEO 挑战产品方向，设计师检查 UI 品质，工程师锁定架构，他用这套配置 60 天写了 60 万行生产代码。

地址：github.com/garrytan/gstack

7、agency-agents，52k+ stars，147 个职业角色模板，覆盖前端、后端、DevOps、设计、产品、内容策略、营销、社区运营等 12 个部门。 英文版：github.com/msitarzewski/agency-agents 中文版：github.com/jnMetaCode/agency-agents-zh

8、Product-Manager-Skills，46 个产品经理技能模块。JTBD 分析、用户故事地图、优先级排序、竞品分析、发现访谈、定位声明。

地址：github.com/deanpeters/Product-Manager-Skills

9、AiCMO-Marketin，营销和运营方向，按职能模块组织：品牌策略、内容营销、SEO、社媒运营、广告投放、用户增长、数据分析。相当于给 Agent 装了一整个营销部门的脑子。

地址：github.com/AICMO/AiCMO-Marketing-Prompt-Collection

10、codebase-to-course，把任意代码仓库变成一个单页交互式 HTML 教程。带动画可视化、嵌入式测验、代码和白话对照 地址：github.com/zarazhangrui/codebase-to-course

"让 AI 变聪明"是模型公司的事，我们能做的是把工作沉淀 MD 文档，把它变有用。
