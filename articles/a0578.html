整理一下藏师傅开源的所有 Skills

Claude-to-IM-skill： 1800🌟 安装后可以将你的 Claude Code 和 Codex 连接到任何聊天软件，实现远程控制 https://github.com/op7418/Claude-to-IM-skill

Video-Wrapper-Skills： 200🌟 自动为你的视频添加类似“小Lin说”那样的解释特效，支持高亮卡片、关键词卡片、作者介绍、社交媒体卡片等多种组件 https://github.com/op7418/Video-Wrapper-Skills

Youtube-clipper-skill： 1700🌟 帮你从 YouTube 下载长视频，并在分析视频后给出“长剪短”的方案，同时会自动添加中英双语字幕。 https://github.com/op7418/Youtube-clipper-skill

Document-illustrator-skill： 300🌟 自动分析文档并生成配图，支持 16:9 和 4:3 比例。它会按照你的分段生成多张配图，并支持多种风格选择。我常用的封面图就是用这个生成的。 https://github.com/op7418/Document-illustrator-skill

Humanizer-zh： 5600🌟 去除 AI 生成文档中常见的“AI 味”表述，采用两段式处理，帮你提升 AI 生成内容的观感。 https://github.com/op7418/Humanizer-zh

NanoBanana-PPT-Skills： 2100🌟 基于 AI 自动生成高质量 PPT 图片和视频的强大工具，支持智能转场和交互式播放，带有非常顺滑的转场动效。 https://github.com/op7418/NanoBanana-PPT-Skills
