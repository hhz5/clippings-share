你有没有想过，不用写 Prompt，画几笔就能让 AI 出图？

最近社区里被一个 AI 工具刷屏了。

它叫 Jaaz ，是我们目前见过 最像“魔法”的开源 Agent 工具 ！

我们今晚 8 点特别邀请了Jaaz 主创团队， 一起来直播间聊聊 Jaaz 的故事。 点击预约占座 👇

你只需在一块画布上随便涂涂写写，它就能自动生成一张完整的图，连 prompt 都不用敲。

比如，你想把labubu二创一下，只需甩两张图，画上符号，一个新IP就出来了。

放背景图，画个箭头，角色就无缝闪现到沙滩上。

或者，你想生成一张图，只需简单画几笔，Jaaz 就能准确理解前景、背景、风格、人物位置。

用动物替换图中的人，也十分丝滑。

你还可以随意拼贴，在画布放上所需元素，画个箭头，马上出图海报大片。

Jaaz 这种全球首创的交互形式，完全刷新了以往的创作方式。

这只是 Jaaz 的特色功能之一： 魔法画布 。随便画，随手写，AI 全懂！

为了让你更直观地感受 Jaaz 的强大， 今晚 8 点 ，「通往AGI之路」直播现场，不仅会拆解魔法画布，还会展示：

  • 一句话批量生成绘本

  • 一句话批量生成脚本分镜

  • 一键批量生成多个背景

  • 制作 AI 虚拟偶像 MV

这些以前要找设计师、剪辑师、画师……才能做的，现在你只要会打字、画几笔，Jaaz 就能替你搞定。

🌟 Jaaz 是什么？

看完上面这么多案例，你可能会好奇：Jaaz 到底是怎样一款工具？它还能做什么？和 Lovart、星流这种创意设计 Agent 相比又有哪些优势？

优势1：Agent 批量生成，效率拉满

Jaaz 最大的爽点之一，就是自研的 Agent 能力。

只需要简单和它聊几句，1-2 分钟就能批量出图，新手小白也能做出高质量的内容。

而且，你还可以自定义系统提示词和 Agent 知识库，高度可控，让它更懂你。

优势2：本地+云端混合，省钱又安心

担心 API 模型太贵？追求数据本地化的安全感？Jaaz 为你提供了完美的解决方案。它支持 Ollama、ComfyUI 等本地部署，也能与远程 API 配合使用。

这意味着，你不仅可以在本地免费、无限次地运行模型进行批量生成，还能连接到云端，无缝接入业内最新的顶级模型（如 GPT-4o、Flux、Google Veo 等），非常灵活。

优势3：魔法画布，重塑创意工作流

这是 Jaaz 的全球首创交互形式。它不是一张简单的画板，而是一个可视化的创意沙盘。

你可以直接拖角色、换背景、加道具、布局场景，甚至用笔划几笔写几个字，AI 就能明白你的意思。

不用写复杂提示词、也不用来回调整细节，你只管动手，Jaaz 负责还原你的脑洞。

优势4：视频批量生成

它支持集成 Seedance、Veo3 等主流视频模型，想做 AI 动画、短视频、视觉 MV，完全没问题。

而且还能智能调用你设定好的 ComfyUI 工作流 ，创作功能更全面高效。

优势5：本地素材管理方便

生成的图太多不好找？

Jaaz 在本地素材管理上也十分贴心，它会显示生成模型、Prompt 信息，一目了然。

还有更多新功能，例如一键同款、MCP 等正在路上，敬请期待！

🔧 Jaaz 如何使用？

第一步：下载 Jaaz 最新版本

下载自己电脑对应系统的版本，或在网页使用。

  • 本地部署： https://github.com/11cafe/jaaz/releases
  • 官方网站： https://jaaz.app/ （网页暂不支持批量生图）

第二步：登录获取各模型使用权限

  1. 1\. 目前软件已经可以登录，登录后即可获得免费生图次数，用完后在登录的网站续费即可，直接可使用各种主流模型。当前新登录用户送一小部分额度可以直接生图，名额有限，先到先得～

  1. 2\. 登录后跳转到官网，用 google 邮箱登录即可（后续会支持其他邮箱登录）；

  1. 3\. 可以直接充值任意额度（支持微信、支付宝）进行生图，内测阶段 API 没有差价，无需月费，可任意使用。

第三步：对话轻松批量生图

然后返回程序中，需选择一个文本模型，再选择 Jaaz 下的一个生图模型，输入提示词就可以制作啦！

以上，就是 Jaaz 的完整使用教程，期待你做出满意的作品！更加详细的使用教程，请移步 Jaaz 新手使用说明书查看。

  • 网页体验链接： https://jaaz.app
  • 本地部署下载地址： https://github.com/11cafe/jaaz
  • Jaaz新手使用说明书： https://waytoagi.feishu.cn/wiki/UZCCw8ZEsiRNOCkIpV9cOuWsn5g

🤳🏻 “我们为什么要做 Jaaz？”

看完这些，Jaaz 有没有满足你对一款 AI 创意设计工具的全部幻想？

Jaaz 的诞生，其实源自主创团队在创作中的痛点。

从一开始探索 AI 图像工具、开源 ComfyUI 插件，到尝试做线上平台搭建，他们一路上踩了不少坑：

工具门槛高、素材不好管理、模型调用太贵、流程还割裂……

每次灵感来了，还得在好几个平台之间来回跳，创作的效率和体验都被严重拖慢。

后来他们试用了 Manus 这类工具，虽然很有启发，但也发现还远远不够。于是他们决定亲自下场，打造一个 真正开源、多模态、一站式 的创作入口。

Jaaz 就是他们给出的一种解法：

对新手来说，一句话就能出作品；

对高手来说，可以在魔法画布上随心所欲地发挥；

对所有创作者来说，它都在努力降低“将想法变为现实”的门槛。

他们不只想做一个“能用”的 AI 工具，而是要打造成 下一代创作者的首选多模态创作平台， 一个真正意义上的“全模态创作入口”。

不管你灵感来自文字、图片、声音，还是 3D，只要你有想法，Jaaz 都能帮你无缝转化为超预期的作品。
